# State

Where things stand **now**. Present tense only: replace lines, never append history (`git log` holds that). Update it in the same commit whenever what is live or in flight changes.

## Live

- The app is Noodle Pads at https://noodlepads.com/ (ADR 0010), served by one Worker (`worker/`, the `/api` routes) and one D1 database, `noodle-pads` (ADR 0002). The old address is retired (ADR 0010, 2026-10-13): the move page and the app's receiving end are gone, and its Worker and flarepress folder are deleted. Manage the database with `just cloud-migrate`, `cloud-profiles`, `cloud-prune`, `cloud-reset-pin`, `cloud-sql`, `cloud-backup` and `cloud-db` (README "Running it yourself" lists every recipe).
- Release 1.0 (CHANGELOG.md). The corner says when the live build went up ("Updated Oct 19, 9:27 PM", the device's time); About adds the release and the commit, a link to it on GitHub ("Updated Oct 20, 12:01 AM · 1.0.217 · f52728b"); the footer shows no release number. The release, `1.0.<commit count>`, lives in `web/version.js` (`just version`; CI, `just ship` and `just land` check it). The name is `noodlepads` in backups, beat files and downloads (older `noodle-pads` files still load); the browser database and the D1 database keep `noodle-pads`. The Cloudflare ids live in `~/.config/noodlepads/cloud.json`, not the repo.
- noodlepads.com serves `main`: its `version.json` names the release and commit (`v1.0.215-4d5ef56`, flarepress `release=`) (`just deploy-verify` checks it; `just live` and `just doctor` compare it with `main`). GitHub deploys every push to `main` (`.github/workflows/deploy.yml`, ADR 0025) with this repo's own token, through the public flarepress action; `site/` is the site folder. Agents never deploy. GitHub runs `just test` on every push (`.github/workflows/test.yml`) and checks the live site daily (`just live-check`, `.github/workflows/live.yml`).
- Every commit to `main` is deployed (`just --yes deploy`), then checked live: `just cloud-smoke` (the API) and `just cloud-e2e` (two devices syncing). `just cloud-prune --smoke` clears what a killed check left.
- Feedback (Ben, 2026-10-19), live since `b6df858` (deploy run 117, 2026-10-19): ⚙️ Settings → About → Feedback, behind the grown-up sum at every level (`web/grown-up.js`, shared with 🧸 Kids' ⚙️), opens Send feedback, centered on every width (`web/feedback.js`); Send posts the text as typed to `POST /api/feedback`, flarepress's shared `handleFeedback` (vendored in `worker/events-worker.js`), into the shared R2 bucket `app-suggestions` (binding `FEEDBACK`, rate limit `FEEDBACK_LIMITER`); the telemetry runner's daily pull moves it to Ben's notes, kept 90 days. The public policy says so (privacy.pdxfixit.com/noodlepads, 2026-10-19). Not yet tried on a phone or sent for real.
