# 0003. One shared kit of sounds, copied into every person's board

- **Status:** Accepted
- **Date:** 2026-10-10
- **Decided by:** Ben, 2026-10-10: one kid "wants the same sounds; maybe everyone has the same default sounds"

**In short.** `boards.json` lists one kit of sounds in named groups. Every person, added people included, gets their own copy of each kit sound. A person's own recordings stay theirs. Renames, hides and order changes on a kit sound apply to that person only.

## Context

- One kid asked for many sounds, and then another wanted the same ones. Keeping a separate list per person meant copying entries by hand.
- Each person edits their board: they rename, hide and reorder pads. Those edits must not change anyone else's board.
- The beat maker's sound chooser should list each kit sound once, not once per person.

## Decision

- `boards.json` has top-level `kitGroups` (drums, notes, chords, bass, game, effects, voices, silly) and `kit` (each sound names its `group`).
- `model.kitFor(personId, kit)` makes a copy per person with the id `<person>-<kitId>`, marked `kit: true`. `mergePeople(..., {kit})` adds the kit to every person, added ones included.
- Each person's own sounds come first on their board ("My sounds" or "<Name>'s sounds"), then the kit in collapsible groups.
- The beat chooser shows the kit once, from the current person's copies, then each person's own sounds.
- Backups accept edits to kit copies (`kitIds` in `backup.js`), so a restored board keeps its renames and hides.

## Options turned down

- **One kit shared by reference.** One person's rename or hide would change everyone's board.
- **Separate defaults per person.** Duplicated entries, and one kid's wish for another's sounds would have meant copying them by hand.

## Consequences

- Adding a kit sound is one line in `boards.json` and a clip in `web/clips/kit/` (generated by `tools/make_placeholders.py`).
- Copy ids depend on the person id. A person's id changes only once, from an older plain id to a random one (ADR 0002), and then every copy id and every record naming one is rewritten with it (`web/reid.js`).
- Revisit if people should share edits, for example one family-wide rename.
