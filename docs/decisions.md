# Decisions

The rules Ben has decided that are true **today**. This file outranks every other doc.

How to use it:

- One row per rule: **Rule · Why · Since**. Rule and Why together stay under 40 words.
- **A replaced rule is deleted here,** and the new rule takes its row. Never add a note that a rule was replaced.
- "(to build)" means Ben decided it and the code does not do it yet. The work is in [TODO.md](../TODO.md) "Agents do".
- A new rule goes in the right section, in the same commit as the work. A significant one also gets an ADR in [adr/](adr/README.md).
- Nothing here is yours to change. You may record an answer Ben gave, or fix a row that does not match the code.
